# Lockjaw on celld

The public celld Alchemy layer is coming. It is not in this release yet.

It depends on `@rat-king/alchemy-nest` from the [Rat King](https://github.com/joelhooks/rat-king) repo, which isn't on npm. The layer will pin it at an exact commit. No copy of it is included here.

The Worker and its Durable Object classes remain shared with the Cloudflare layer. This stub does not deploy anything and is not a tested celld installation guide.
